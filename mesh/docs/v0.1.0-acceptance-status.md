## Packaging checks done on the build box (supporting AT-H8, not replacing it)

- `packaging/build-deb.sh` → `task-mesh_0.1.0_amd64.deb` (native build). `packaging/build-deb.sh -aarm64 -d` → `task-mesh_0.1.0_arm64.deb` (cross-built; the package is pure Python, but the **arm64 package has not been installed anywhere**).
- lintian: 2 warnings only (`no-manual-page`; `appstream-metadata-validation-failed`, because the component ID isn't reverse-DNS and the homepage is a placeholder).
- `sudo apt install ./task-mesh_0.1.0_amd64.deb`: deps resolved from trixie; postinst byte-compiled 101 modules; `task-mesh --version` → `task-mesh 0.1.0`; `sudo task-mesh` → refused, exit 2; `QT_QPA_PLATFORM=offscreen task-mesh` as uid 1000 → started, created XDG dirs (0700) and a WAL DB, reached NO_DEVICE, kept running until killed after 8 s.
- `sudo apt purge task-mesh` → `/usr/bin/task-mesh`, `/usr/lib/task-mesh`, the desktop file and icons removed; user data under XDG dirs left alone (by design; `task-mesh --forget-user-data` removes it).
