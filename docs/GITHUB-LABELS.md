# Proposed GitHub labels

These labels are not created until the repository is published. A maintainer
can create them from this list (names and colours are suggestions).

| Name | Colour | Use |
|---|---|---|
| experimental-alpha | `#B60205` | This report is about the unvalidated public alpha |
| triage | `#FBCA04` | New issue, not yet classified |
| bug | `#D73A4A` | Something does not work |
| enhancement | `#A2EEEf` | A requested improvement |
| testing | `#0E8A16` | Volunteer test report or test-harness work |
| hardware | `#1D76DB` | Boards, radios, GPS, SDR |
| compatibility | `#1D76DB` | Works / does not work on a device |
| installer | `#5319E7` | Installer, packages, checksums, uninstall |
| documentation | `#0075CA` | Docs, issue templates, release notes |
| security | `#B60205` | Public follow-up to a security fix (not the private report itself) |
| blocked | `#000000` | Waiting on a decision, missing hardware, or a known blocker |
| good first issue | `#7057FF` | Suitable for a new contributor |
| question | `#D876E3` | Better as a Discussion; may be converted |
| invalid | `#E4E669` | Not a T.A.S.K. issue, or not enough information |
| duplicate | `#CFD3D7` | Already tracked elsewhere |
| wontfix | `#FFFFFF` | Will not be changed, with a reason |
| core | `#C5DEF5` | task-core / compat |
| launcher | `#C5DEF5` | task-launcher |
| mesh | `#C5DEF5` | task-mesh |
| maps | `#C5DEF5` | task-maps |
| radio | `#C5DEF5` | task-aprs / planned task-radio |
| sdr | `#C5DEF5` | task-sdr |
| resources | `#C5DEF5` | Offline library / medical reader |
| console | `#C5DEF5` | Devices / task-console |
| windows | `#E4E669` | Windows; not supported in this alpha |
| pi5 | `#0E8A16` | Raspberry Pi 5 specific |

Issue templates already apply a subset of these (`bug`, `triage`,
`experimental-alpha`, `testing`, `hardware`, `compatibility`, `installer`,
`enhancement`).
