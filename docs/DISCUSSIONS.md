# GitHub Discussions guide

Discussions are for conversation; Issues are for actionable bugs and requests.

Suggested categories (to create when the repository is published):

| Category | Format | Use it for |
|---|---|---|
| 📣 Announcements | announcement (maintainers only) | Releases, test calls, safety notices |
| 🙋 Q&A | question/answer | "How do I…", setup help |
| 📡 Hardware & Radios | open | Boards, Meshtastic nodes, GPS, SDRs, APRS radios — share what works |
| 🧪 Testing Calls | open | Coordinated tests of a release candidate; post results in the thread |
| 💡 Ideas | open | Feature ideas before they become issues |
| 🌍 Deployments & Stories | open | How your team or community uses T.A.S.K. |
| 🛠 Development | open | Architecture, Windows port, packaging |

Etiquette: follow the Code of Conduct; redact callsigns, locations and device
serials unless you choose to share them; never encourage unlicensed transmission;
say clearly what you tested and what you did not.
